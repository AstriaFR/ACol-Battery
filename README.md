# ACol 电池

<img src="src/main/assets/webroot/assets/acol-icon.png" width="88" alt="ACol 电池图标">

ACol 电池是一款面向已 root 的 Android 设备的电池监测应用，支持后台充放电记录、耗电分析、游戏性能统计和电池健康趋势。

[下载最新 APK](https://github.com/AstriaFR/ACol-Battery/releases/latest)

## 安装与使用

应用需要 Android 13 或以上、ARM64 架构，以及可授予应用 root 权限的环境。基本充放电记录可使用兼容的电池接口。详细电池信息和截止电压调整则需要较新的 OPLUS 厂商节点。

安装 APK 后，首次打开时授予 root 权限。应用会检查设备提供的接口，并准备后台记录。部分功能受限时，可按提示继续使用。若提示记录所需的电池读数暂不可用，可先进入应用，稍后在「设置」中开启记录并重试。若初始化失败，可在错误报告中查看原因。

记录开启后，可在「首页」查看实时状态，在「记录」回看充放电曲线和耗电统计，并在「设置」调整采样间隔。关闭应用界面后，后台仍会继续记录。

## 主要功能

- **实时电池状态**。首页显示当前电量、剩余容量、电流、电压、温度和功耗。
- **充放电记录**。自动划分充电与放电记录，支持按类型和年月筛选。详情页支持曲线缩放和 CSV 导出。
- **耗电分析与续航估算**。查看亮屏和息屏耗电、分时耗电及应用耗电分布。根据当前电池状态和记录中的使用强度估算剩余能量及可用亮屏时长。
- **使用时间统计**。从首页进入日、周、月视图，查看使用时长和应用分布。统计独立于充放电记录。
- **游戏性能统计**。记录游戏期间的功耗、帧率、CPU/GPU 指标和内存用量，可与普通记录同时运行。
- **性能监视器**。在屏幕顶部显示帧率、各 CPU 核心使用率、当前最高活跃核心频率、GPU 频率与使用率、瞬时功耗、电池电量和温度。它可独立使用，在设置和控制中心均可开关。
- **电池信息与健康趋势**。查看电池容量、健康度和循环次数。支持自动或手动保存电池快照、查看历史趋势，以及在兼容设备上调整截止电压。

说明：放电记录功耗和应用耗电统计通过电量计电量(battery_rm)变化得出，优点是只需要几分钟记录一次，几乎无开销，缺点是存在应用功耗分配误差，以及电量100%和接近0%时可能出现电量计校准导致的较大偏差。

## 数据管理

记录和统计保存在设备本地，应用无需联网。可在「设置」中管理记录保留策略、导出备份或从备份恢复。
