参数说明

使用须知：进阶选项接口依赖OPLUS厂商节点，存在情况视机型而定。虽然这些接口都会受到更底层的限制，但若设置不当，仍可能会导致手机寿命非正常下降。修改前应了解其意义，并合理地修改。参数修改只生效一次，可直接恢复，硬重启后会失效，不影响系统分区。

「当前生效值」显示驱动接口的读回结果。电压和电流的读回值可能是阈值或协议目标，实测值还会随充电器、电池状态和温度变化。显示「接口缺失」的接口无法在这台设备上使用。

解容

电量计截止电压（GAUGE_TERM_VOLTAGE）：电量计估算剩余容量时使用的放电终点。调整后，低电量读数可能要经过后续充放电才会重新校准。

软件关机电压（GAUGE_SHUTDOWN_VOLTAGE）：供系统低电压关机策略使用的阈值。实际关机时机还受负载引起的压降和系统保护策略影响，可与电量计截止电压分开设置。

厂商截止与关机目标（TARGET_TERM_VOLTAGE、TARGET_SHUTDOWN_VOLTAGE）：厂商策略为上述两个阈值计算的参考值，仅供查看，可能与手动覆盖后的生效值不同。

浮充降压修正（DEC_DELTA）：参与厂商对充电目标电压的降压计算。0 表示不加手动修正；写入后由驱动在满足条件时重算，修改量不一定会立即等量反映到电压上。

实际浮充降压量（FV_DEC）：驱动当前算出的降压量，只读。可用它查看修正是否已经反映到厂商的降压结果。

浮充电压上限（FV_MAX）：驱动为电池设定的充电目标上限，通常受温度和厂商降压策略影响。

浮充电压下限（FV_MIN）：驱动在浮充上限和其他电压限制中取较低值，作为有线充电的目标电压。这里的「下限」是取低值的结果，不是电池电压必须保持的最低值。

充电

充电降温限流档位（COOL_DOWN）：选择厂商的充电降温电流档位。各档对应的电流由设备和充电协议决定，并非固定的电流或温度阈值。详细档位

限制充电：四个选项互斥。「无」解除手动限制，交回系统；「暂停」让驱动暂停给电池充电；「禁止」挂起有线充电输入；「旁路」请求厂商旁路模式，是否开启由驱动根据接入和电池状态决定。

电流计采样间隔（GAUGE_UPDATE）：决定充电和放电时电流读数多久更新一次。App 的记录和曲线采样间隔在设置页单独调整。启用自动覆盖时，性能功能启动后可能改写这个值。

普通有线电池电流（WIRED_FCC）：限制普通有线充电时流入电池端的电流。

普通有线输入电流（WIRED_ICL）：限制普通有线充电时 USB 端从充电器取用的电流。输入端与电池端的电压可能不同，两边的电流不能直接比较。

PPS 电流（PPS_CURR）：USB PD PPS 模式下的协议电流目标，仅在使用 PPS 时适用。

UFCS 电流（UFCS_CURR）：UFCS 融合快充模式下的协议电流目标，仅在使用 UFCS 时适用。

VOOC 电流（VOOC_CURR）：VOOC 或 SUPERVOOC 模式下的协议电流目标，仅在使用对应协议时适用。

修改在确认时应用一次。输入页的「恢复默认」撤销这一项的手动设置，进阶设置右上角的「恢复默认」撤销本页的手动设置。恢复后的值由厂商策略决定。

详细档位

0 档取消降温降流，PPS、UFCS 在 0 档使用表内最高电流。其他充电限制继续生效。「恢复默认」会撤销手动设置，由系统选档。

每张表只列到对应协议的配置上限。电流为档位对应的限制值，实际电流还受充电器、电池状态和温度影响。

两个原始值怎么算？

系统显示的容量和健康度，可能加过厂家为当前截止电压设置的补偿。这里尝试把补偿前的数值倒推出来。

原始电池健康：找到厂家对应的补偿比例，把显示的健康度按这个比例还原。

原始满充容量：根据还原后的健康度，估算当前的容量补偿，再从显示的满充容量里扣掉。

未触发补偿时：当前截止电压低于本机补偿表的最低档位（或该档偏移为 0）时，无需还原，读取到的满充容量接近实际值。

触发补偿时：当前截止电压命中本机补偿档位时，按对应参数还原，计算出的原始满充容量接近实际值（达到上限封顶时显示下界范围）。

估计锁容容量：用最大化学容量减去当前绿色的满充容量（未补偿时用读取值，已补偿时用原始值），括号内的负百分比表示与最大化学容量的差值比例。

游戏性能统计

用于观察游戏等场景下的性能与耗电变化，结合曲线分析流畅度、温度和功耗表现。开启后生成独立记录，不影响普通充放电统计。

可在控制中心添加“游戏性能统计”快捷开关，无需打开 App，即可开始或结束记录。

电流计采样间隔覆盖

打开此开关后，启动游戏性能统计或性能监视器时，会尝试将上方的「功耗采样间隔」应用到手机电流计。此功能需要设备提供 OPLUS 的 GAUGE_UPDATE 投票节点。设置成功后，充电和放电时的电流读数都按此间隔更新。

剩余能量与时长

剩余能量：用当前剩余容量，乘以按当前电压和预设关系表估算的后续平均电压。

亮屏时长：用剩余能量，除以本条记录的亮屏平均功耗。后续使用强度变化，实际时长也会变化。
